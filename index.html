Viva Voce Questions & Answers

Q1. Why are Arrays of Structures used in this project?

An array of structures allows grouping heterogenous attributes of a patient (integers for ID/age, character arrays for name/disease) into a single entity, and storing multiple such records contiguously in memory for indexed retrieval.

Q2. How is patient deletion handled in C?

When a patient at index idx is deleted, elements from idx + 1 to count - 1 are shifted left by one position, and the counter is decremented: patients[i] = patients[i + 1].

Q3. How is persistent storage achieved?

Using standard C file I/O (fopen in "w" and "r" mode), records are serialized with delimited formatting to hospital_data.txt, surviving program restarts.
